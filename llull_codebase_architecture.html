Boundary-Enforcement Plane

Documented = enforced

The architecture in BACKEND_PYTHON_API_GUIDELINES.md becomes binding through CI. scripts/check_layer_deps.py v2 lints every layer edge in both directions, including deferred imports. core/ protocols break the actual cycles.

📜 layer_rules.yaml

Single source of truth for allowed inter-layer edges. Docs are generated or linted from this file.

layers.tools.depends_on: [memory, config, core, logger, utils]

🔍 check_layer_deps v2

AST-walks module-load + deferred imports + re-export laundering. Both directions, all layers.

CI hard gate · pre-commit · --baseline ratchet mode

🧬 SupportsObjectBus

Protocol in core/protocols.py. logic.bus publishes; agents, tools consume.

put · get · get_objects_for_session

🧬 SupportsBuildChatModel

Protocol breaks tools → logic.llm module-load cycle.

__call__(slot, role=None, max_tokens=None) → BaseChatModel

🧬 SupportsQueryEnhancer

Protocol replaces direct tools/QueryDatabase → logic.query import.

enhance(query: str) → EnhancementResult

🧬 SupportsQueryContext

logger/ becomes a leaf; logic/ writes through the protocol.

get_query_id · set_query_id · clear_query_id

🚫 ImportError Allowlist

try/except ImportError permitted only for genuinely optional providers.

allowlist: langchain_together · langchain_openai · serpapi

🚷 No-Test-Branching Lint

Forbids 'pytest' in sys.modules, PYTEST_CURRENT_TEST checks in production code.

scope: app/ · agents/ · logic/ · tools/ · memory/

🛑 No-OS-Environ-Mutation

Lint blocks module-level os.environ = ... outside tests/_allowed_globals.py.

conftest.py uses monkeypatch fixtures, not module-load mutation

📐 Size-Budget Lint

File LOC, class methods, function-scope imports, broad-except counts. Ratchet only down.

governance/size_budgets.yaml · per-file exceptions with sunset

📚 docs_lint

Every file path cited in *.md must exist. Tree diagrams generated from the file system.

scripts/render_tree.py · pre-commit · docs are build artifacts

🏛️ Governance YAMLs

Every artifact has owner. Layer rules, exceptions, deprecations, size budgets, feature-flag specs.

governance/{layer_rules, layer_exceptions, deprecations, size_budgets}.yaml
